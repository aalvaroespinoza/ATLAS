# Skill: ATLAS UI & Design System

## Cuándo Utilizar esta Skill
Utilizar esta skill al diseñar, modificar o evaluar componentes Razor, estilos CSS/Tailwind, animaciones o pantallas de `ATLAS.UI`.

## Referencias Principales
- **Producto & Filosofía Visual:** `@docs/ATLAS_PRODUCT.md`
- **Referencia Visual de Interfaz:** `/reference/atlas-home-reference.png`
- **Reglas de UI:** `@.agents/rules/atlas-ui.md`

## Reglas Visuales Principales
1. **Paleta Obsidiana/Índigo:** Canvas `#090B10`, Dock `#10141E`, Superficie `#121724`, Acento Hero `#6366F1`.
2. **Profundidad Satinada:** Gradientes oscuros sutiles (`from-[#141a29]/90 to-[#0e1320]/90`), bordes milimétricos `border-white/[0.08]` y backdrop blur.
3. **Resplandor Semántico:** Verde esmeralda para hábitos/ingresos, violeta para roadmaps, rosa para gastos.
4. **Microinteracción Física:** Curva `cubic-bezier(0.16, 1, 0.3, 1)`, scale `0.98` en click activo y transiciones rápidas (120ms-150ms).
5. **Anti-Dashboard:** Cero métricas decorativas sin datos reales de SQLite.
