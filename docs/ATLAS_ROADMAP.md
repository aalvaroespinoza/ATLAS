# ATLAS — Hoja de Ruta (Roadmap)

> **Estado y Planificación de Fases**  
> Este documento organiza el progreso del proyecto por bloques de trabajo. Se ejecuta una fase a la vez.

---

## FASE 0 — Preparación de Contexto
- **Estado:** EN PROGRESO
- **Objetivo:** Establecer la estructura de contexto, documentación, reglas y skills para el trabajo con agentes en Antigravity.
- **Entregables:**
  - Estructura `.agents/` con rules, skills y workflows.
  - Creación de `docs/ATLAS_PRODUCT.md`, `docs/ATLAS_ARCHITECTURE.md` y `docs/ATLAS_ROADMAP.md`.
  - Preparación del directorio `reference/` para referencias visuales y de arquitectura.
  - Simplificación operativa de `AGENTS.md`.

---

## FASE 1 — Reconstrucción Visual y UX Basada en las Referencias
- **Estado:** PLANNED (No implementar todavía)
- **Objetivo:** Ajustar y pulir la experiencia visual y los flujos de usuario tomando como base estricta las imágenes depositadas en `/reference/` (`atlas-home-reference.png` y `atlas-architecture-reference.png`).
- **Alcance:**
